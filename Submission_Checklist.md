# Submission Checklist

Before submitting, confirm each item is complete.

- Problem statement understood and summarized.
- Dataset imported from `Master Energy_Utilities_Data.xlsx`.
- Data cleaned and processed.
- Missing values handled.
- Duplicate records removed.
- Date columns standardized.
- Star schema or clean data model created.
- EDA completed.
- Asset/region/threat risk analysis completed.
- Segmentation completed using RFM or similar method.
- Anomaly detection completed using rule-based and statistical logic.
- KPI dashboard created.
- Forecasting completed for future incidents or risk values.
- Cohort/retention analysis completed.
- Technical report written.
- Dashboard screenshots added to report.
- Python/SQL/Power Query/DAX scripts included.
- Final recommendations written.

Suggested final ZIP contents:

- Technical report.
- Dashboard file or screenshots.
- Cleaned dataset.
- Analysis scripts.
- README.
